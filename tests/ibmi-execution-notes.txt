# "Cause" column of the wiki page IBM-i-Execution-Results
# (scripts/execution-wiki.py). scripts/ibmi-execution.sh records WHAT each
# program displayed on IBM i; this file records WHY it differs, which only a
# person can establish. A difference with no entry here shows as
# "not yet investigated".
#
# Format:  <file>  <category>  <reason>
#
#   rpgc      rpgc does something other than IBM i: work to do
#   platform  a deliberate difference that follows from the target platform
#   test      the test relies on something IBM i does not do
#   open      looked at, cause not established yet
#
# When a fix lands, delete its line: a program that behaves the same needs
# no note, and a stale one hides a regression.
